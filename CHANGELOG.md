# Changelog

All notable user-visible changes to the FileGator TOS application package.

## 7.16.9-1 — 2026-11-14

### Added
- First release. FileGator (`filegator/filegator:v7.16.9`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8063 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/filegatordocker/`.
